# README Design Notes / README 设计说明

## English

This repository's documentation was written for a source-only evidence tool, not copied from another project's claims or screenshots.

Primary references reviewed:

| Repository | Useful pattern | Adaptation here |
| --- | --- | --- |
| [Best-README-Template](https://github.com/othneildrew/Best-README-Template) | Clear contents, prerequisites, setup, usage, contribution and license sections. | Keep those navigational layers, but replace generic setup with tested commands and explicit private-data boundaries. |
| [FastAPI](https://github.com/fastapi/fastapi) | A focused introduction followed by a small runnable start and deeper documentation. | Offer synthetic checks first; move long configuration and pitfalls to linked guides. |

Both are established, widely starred GitHub references. Star counts are time-dependent and are not a quality certificate for this project. No borrowed badges, production claims, sponsors, screenshots, or testimonials appear here.

Chosen format:

1. One complete English section, followed by one complete Chinese section in every main guide.
2. One H1 title; meaningful H2/H3 levels; blank lines around lists; language-labeled code fences.
3. Relative links for repository files; primary-source links for external tools/design references.
4. A short README with linked ordered setup, processing contracts, architecture, troubleshooting, and privacy boundaries.
5. Commands distinguish synthetic checking, authorized capture, local processing, and verified delivery.
6. Tables compare prerequisites/status/flags, while small trees/flows explain lineage. Decorative badges and fictitious screenshots are omitted.

The source's English/Chinese comments explain intent, invariants, recovery, and privacy boundaries; comments do not claim an omitted integration exists. The open-source workbook preview is labeled as a layout preview, not an Office rendering certificate.

## 中文

本项目文档针对“源码版证据工具”重新编写，没有复制其他项目的成就或截图。

查看的第一手参考：

| 仓库 | 可参考的模式 | 本项目如何使用 |
| --- | --- | --- |
| [Best-README-Template](https://github.com/othneildrew/Best-README-Template) | 清楚的目录、前提、安装、使用、贡献和许可证。 | 保留导航层次，把泛用安装例子换为实际命令和私密数据边界。 |
| [FastAPI](https://github.com/fastapi/fastapi) | 集中介绍、小型可运行入口，再链接深入文档。 | 先让读者跑合成检查，长配置和避坑放到独立指南。 |

二者都是成熟、高星 GitHub 参考。星数随时间变化，也不能替本项目证明质量。没有借用其徽章、生产承诺、赞助、截图或评价。

格式选择：

1. 每篇主指南先完整英文，再完整中文。
2. 一个 H1，合理 H2/H3，列表前后空行，代码块标语言。
3. 仓库文件用相对链接，外部工具/设计用第一手来源。
4. README 保持入口，链接顺序配置、处理契约、架构、避坑、隐私边界。
5. 命令分清合成检查、授权采集、本地处理和最终验收。
6. 表格比较前提/状态/参数，小树/流程说明血缘；不放装饰徽章和假截图。

源码中英文注释解释意图、不变量、恢复与隐私边界，不能声称未包含的集成已存在。开源表格 PNG 明确是布局预览，不是 Office 原生渲染证书。
