# Changelog

## English

### 1.0.0

- Public, independently copied source release with an MIT license.
- English-first bilingual documentation and operational comments.
- Explicit single-record binding, crash recovery and cross-process ownership locks.
- Shared recursive archive expansion budgets and atomic per-object persistence.
- Signed URL redaction, strict attachment provenance and separate business/capture timelines.
- Portable local tool selection and explicit expected-count configuration.
- Open-source ExcelJS workbook authoring and Sharp layout previews.
- Synthetic tests, source privacy checks, documentation checks and CI.

No real business records or authenticated browser state are distributed. Synthetic checks do not certify source-system completeness or successful capture on another machine.
